| 脚本 | 量什么 | 当前结果 |

| `scripts/animation-check.mjs` | 展开过程中内容的 opacity 收敛时间 | opacity **从未低于 0.95** |

| `scripts/fix-check.mjs` | 主键可选 / 抽屉滑入 / 点空白退出 / 配对码刷新 | **9 项断言全部通过** |
| `scripts/screenshots.mjs` | 24 张流程截图 | 全部通过 |
